# Perkėlimo failai

Čia laikomi failai, kurie keliami į veikiančią svetainę atpsprendimai.lt:

- `atp.css` — temos „Simplex v8“ stiliai (`wp-content/themes/salient-atp/assets/atp.css`).
- `pradzia.txt` — pradžios puslapio turinys WPBakery konstruktoriaus elementais.

Demo peržiūrai skirtas failas yra repozitorijos šaknyje (`index.html`).
