# ATP Sprendimai — svetainės dizaino demonstracija

Nestandartiniai metalo gaminiai iš juodo ir nerūdijančio plieno. Titnago g. 19, Vilnius.

**Peržiūra:** https://arvydastry.github.io/atpsprendimai/

Tai naujos svetainės dizaino demonstracija, ne veikianti svetainė:

- Užsakymo forma tik parodo veikimą, laiškas nesiunčiamas.
- Nuotraukos ir vaizdo įrašai — iliustracinė „Pexels“ medžiaga.
- Projektai ir atsiliepimai pavyzdiniai.
- Žvaigždute `*` pažymėti duomenys dar nepateikti: įmonės kodas, PVM kodas, bankas ir sąskaita, darbo laikas, cecho duomenys.

Puslapis pažymėtas `noindex`, todėl paieškos sistemos jo nerodo. Nuorodą galima siųsti tiesiogiai.
